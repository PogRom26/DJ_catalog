# Django Project - Home & Contacts

Простой веб-проект на Django с двумя основными страницами: домашняя страница и страница контактов.

## Описание проекта

Этот проект демонстрирует базовую структуру Django приложения с:

- Домашней страницей (Home)
- Страницей контактов (Contacts)

## Технологии

- Python
- Django
- HTML/CSS

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd django-project
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```
pip install -r requirements.txt
```

### 4. Запуск сервера разработки

```
python manage.py runserver 
```

### 5. Открытие в браузере

```
Перейдите по адресу: http://127.0.0.1:8000/
```

## Настройки

Основные настройки находятся в файле myproject/settings.py:

DEBUG = True - режим отладки (для продакшена установить False)\
ALLOWED_HOSTS - разрешенные хосты \
DATABASES - настройки базы данных
